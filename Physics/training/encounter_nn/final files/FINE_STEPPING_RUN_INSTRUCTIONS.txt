WHAT THIS SCRIPT DOES:
  For each dt (0.06, 0.08, 0.10) compares five methods:
    1. IAS15             — reference integrator
    2. SIMON-noNN        — coarse leapfrog, no correction
    3. SIMON-encounterNN — Fix 1 base model (1 correction max)
    4. finer-Zone3-k2    — noNN + 2 sub-steps in Zone 3 when gate fires
    5. finer-Zone3-k4    — noNN + 4 sub-steps in Zone 3 when gate fires
  Gate (same for both): pair 1-2 in Zone 3 AND vr_norm < -0.40.

  Three levels:
    Level 1 (Global)   — T=100yr single-seed rollout
    Level 2 (Isolated) — all methods from same event-entry state
    Level 3 (Ensemble) — 10 IC-perturbed seeds

IMPORTANT: Script re-runs noNN and encounterNN and validates them against your
  base A and B files before any fine-stepping comparison. If validation fails
  (diff > 0.5%) the script stops. Both validation passes confirm a fair comparison.
